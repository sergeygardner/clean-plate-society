# Clean Plate Society
## Independent iOS Application (Swift)

[Clean Plate Society](https://apps.apple.com/gb/app/cleanplatesociety/id6766110234) turns everyday meals into fun little celebrations for kids.

Earn cute achievement stickers, celebrate clean plates, and build positive mealtime habits with a playful collection of charming characters and cheerful rewards.

Designed for families, the app focuses on encouragement and motivation through fun visuals, collectible sticker-style achievements, and simple daily progress.

Features

- Cute collectible sticker rewards
- Family-friendly mealtime motivation
- Daily achievement celebrations
- Wholesome character collections
- Bright kid-friendly design
- Simple and easy to use
- Positive encouragement without pressure

Whether it’s finishing vegetables, trying new foods, or simply making mealtime more enjoyable, Clean Plate Society helps turn small wins into happy moments.
